O QUE É HTML


HTML é uma linguagem utilizada para estruturar o
conteúdo de páginas da internet.

Algumas Tags em HTML

<h1> - Títulos

<p> - Parágrafo

<a> - Links

<img> - Imagens

<br> - Quebras de linhas

E muitas outras tags que você pode aprender por aqui!

Um exemplo básico de HTML

<html>

    <body>

        <h1>Olá Mundo!</h1>

        <p>Minha primeira página.</p>

    </body>

</html>
