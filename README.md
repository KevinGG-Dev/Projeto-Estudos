# 📚 Projeto de Estudos — Desenvolvimento Web

Projeto desenvolvido durante meus estudos de Desenvolvimento Web na faculdade, com o objetivo de praticar e consolidar os fundamentos de HTML.

O repositório reúne exercícios, páginas e implementações realizadas ao longo das aulas, permitindo acompanhar minha evolução no desenvolvimento web e na utilização de Git e GitHub.

## 🌐 Sobre o projeto

O projeto consiste em um site de estudos que reúne conteúdos relacionados às tecnologias que estou aprendendo.

A página principal permite navegar entre diferentes seções, incluindo conteúdos sobre:

- HTML
- Java
- Git e GitHub
- Formulários
- Navegação entre páginas
- Frames
- Estruturação de páginas web

O arquivo principal do projeto é:

`index.html`

## 🛠️ Tecnologias utilizadas

- HTML5
- Git
- GitHub

Neste momento, o projeto utiliza principalmente HTML, acompanhando os conteúdos estudados durante as aulas.

Novas tecnologias serão adicionadas conforme minha evolução no curso.
